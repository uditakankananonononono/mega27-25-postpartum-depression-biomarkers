# PPD source-unit gate - concrete code artifact, not a biomarker

`audit.py` reads the two source-verified CSV crosswalks, not expression or methylation outcomes, and emits deterministic JSON. It checks GSM uniqueness, labels, postpartum timepoint, source person or library tokens, and the contradictory `DE##` prefixes. The key guard is deliberate: 119 unique GSE290313 full library tokens never imply 119 independent people; the tool refuses person-level transfer eligibility until depositor mapping exists. GSE45603 has 48 explicit source person tokens, but its phenotype/batch and comparator parity still require independent checks. JSON outputs are stored beside the script. Five focused tests cover current source counts, duplicate GSM, conflicting patient labels, wrong timepoint and library-ID pseudoreplication.

Run: `python3 -m pytest -q projects/postpartum_depression/transfer_audit/test_audit.py` and `python3 projects/postpartum_depression/transfer_audit/audit.py --study GSE290313`. Source reference: `../sources/GSE45603_used_sample_crosswalk.csv`, `../sources/GSE290313_used_sample_crosswalk.csv`, and the primary GEO series pages at https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE45603 and https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE290313 . These crosswalks were previously individually fetched and hashed; this run did not re-fetch every GSM or inspect values.

This is a working provenance/QC component prompted by ChatGPT consultation 02, but generic crosswalk checks are not a demonstrated novel research method, biological discovery or published same-task benchmark win. Consequently that consultation remains **0/10 counted novelty-improvement rounds** until an actual distinct, tested novelty improvement is established. No new accession/service credit.
